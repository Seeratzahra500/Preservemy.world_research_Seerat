# CV redesign — design plan (v2, full frontend rebuild)

## Why v1 read as AI-generated
The v1 palette WAS the #1 AI-portfolio cluster: warm cream (#FBF6EE) + terracotta/coral
accent + a serif-ish display. The offset yellow blob behind the photo was the worst offender.
Scrap all of it. New direction must avoid all three AI clusters:
1. cream + terracotta  2. near-black + acid green  3. broadsheet hairline columns.

## Subject
A third-year CS student who *builds things end to end* (full-stack + systems + ML), and who
literally built a set of developer tools. Ground the identity in the engineer's world:
precise, technical, a "spec sheet / ID badge" vocabulary — but on a clean, modern, light canvas.

## Tokens
Color (cool, not warm — deliberate break from v1):
- --paper  #F4F5F7  cool porcelain (NOT cream)
- --ink    #141A24  deep slate (NOT pure black -> avoids cluster 2)
- --cobalt #2B54FF  primary
- --violet #7A5CFF  secondary (the "ML/AI" accent)
- --mist   #E4E7EE  lines/surfaces
- --sky    #EEF2FF  tint surface

Type:
- Display: Bricolage Grotesque (700/800) — characterful modern grotesque, not the serif cliché
- Body:    Inter
- Mono:    JetBrains Mono — dev-authentic; carries the "spec sheet" labels

Structure device: `//` code-comment kickers (`// about`) instead of decorative 01/02/03 —
meaningful in the engineer's world, not fake sequence.

## Signature (spend boldness here, keep rest quiet)
Hero right column = an **engineer ID / spec card**: clean photo on top, then mono key:value
rows (STATUS / SCHOOL / YEAR+CGPA / FOCUS / LOCATION). Replaces the hated yellow blob.
Second bold moment: Contact section on a cobalt→violet gradient. Everything else quiet.

## Rhythm
hero (paper) → about+experience (ONE dark ink band) → education (paper) → projects (paper,
white tiles, always-visible) → skills (sky tint) → contact (gradient). Subtle scroll reveal,
reduced-motion respected, visible focus. No marquee/cursor/spin/noise.
